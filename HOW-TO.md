# How to use this

Owner: Oluwatobiloba Benjamin Ogungbangbe. Not for sale.

Double-click `Start-Here.bat`. A page opens. You do not type a command.

The sample uses fake people. It does not change a real Microsoft 365 account.

## 1. Try the sample

Click **Prepare this computer**. Then click **Run the sample**.

A good result says PASS.

- 5 people were added.
- 1 row was rejected. That row is meant to fail.
- Ada Okoye moved from Finance to Infrastructure.
- Sam Patel was blocked.
- E9999 was not found. No account was made up.

Then click **Show the staff list** or **Open the ticket note**.

## 2. Look up one person

Type `E1001` or `ada.okoye@example.com`.

You see the team, the manager, the groups, the licence, and whether sign-in is allowed.

## 3. What each team gets

Click **Show the team rules**.

The program does not guess groups. Finance gets finance groups. A manager gets the managers group.

**Clear the staff list** removes only the local list. The samples stay.

## 4. Use your own spreadsheet

Copy a new starter, a team change, or a leaver into the box.

Click **Check first**. This does not save.

If it looks right, click **Apply**.

A date must be `2026-10-20` or `20/10/2026`. The team must be Finance, Sales, Infrastructure, or People.

Do not use a real employee file if this folder will be copied to GitHub.

## 5. Microsoft 365, optional

Leave this blank unless an admin gave you the tenant details.

Save keeps them on this PC only. The secret is not uploaded.

Test connection checks the sign-in. It does not create or block a person.
