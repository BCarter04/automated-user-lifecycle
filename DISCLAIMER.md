# Demo disclaimer

This repository is a demonstration. It is not a live identity system.

- It does not connect to Microsoft 365, Entra ID, or any company tenant.
- It does not create, disable, or change a real account.
- The staff list is a local file, `data/directory.json`, created on your computer when you run the sample.
- The people in `samples/` are fake. The tenant name `tenant.example.onmicrosoft.com` is fake.
- Do not point it at a production tenant. Do not paste real employee data into it.
- It is not warranted for production use. See LICENSE.

Run the sample commands first. Read the report. That is the demo.
